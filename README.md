# مدرّس الأورج (Flutter shell + Android overlay)
- pubspec.yaml و lib/main.dart: هيكل Flutter عشان أدوات البناء تشتغل.
- android/app/src/main/java/com/orgteacher: الكود الحقيقي (خدمة إمكانية الوصول + الطبقة + الدروس).
بعد التثبيت: افتح التطبيق ← "تفعيل الخدمة" ← فعّل "مدرّس الأورج" ← افتح الأورج بالعرض ← "معايرة".
